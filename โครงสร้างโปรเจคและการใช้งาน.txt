🔬 2. SENSOR ถูกใช้ตรงไหน พร้อมทั้งตัวอย่าง
========================================

📍 SENSOR MANAGER (utils/SensorManager.js):
├── Accelerometer Sensor (การตรวจจับการเคลื่อนไหว)
├── Light Sensor (การตรวจจับแสง)
└── Motion Detection (การตรวจจับการนอน)

🎯 การใช้งาน ACCELEROMETER:
├── SleepDetectionScreen.js
│   ├── ตรวจจับการเคลื่อนไหวเพื่อหาว่านอนหรือไม่
│   ├── startMotionTracking() - เริ่มตรวจจับ
│   ├── stopMotionTracking() - หยุดตรวจจับ
│   └── Threshold: 0.05 (ความแรงการเคลื่อนไหว)
│
├── MazeGame.js
│   ├── ใช้ Accelerometer ควบคุมเกมเขาวงกต
│   ├── controlMode: 'sensor' หรือ 'touch'
│   ├── setAccelerometerData({x, y, z}) - รับค่าเซนเซอร์
│   └── checkSensorAvailability() - ตรวจสอบเซนเซอร์

💡 การใช้งาน LIGHT SENSOR:
├── LightSensorScreen.js
│   ├── ตรวจจับระดับแสงในห้อง (0-1000 lux)
│   ├── startLightTracking() - เริ่มตรวจจับแสง
│   ├── stopLightTracking() - หยุดตรวจจับแสง
│   ├── Light Threshold: 5 lux (มืด), 100 lux (สว่าง)
│   └── แสดงคำแนะนำการนอน
│
└── SleepHomeScreen.js
    └── ลิงก์ไปยัง LightSensorScreen

🔧 ตัวอย่างการใช้งาน SENSOR:

// การตรวจจับการนอนด้วย Accelerometer
const startSleepDetection = () => {
  startAccelerometerTracking(1000); // อัปเดตทุก 1 วินาที
  setOnSleepDetectedCallback((data) => {
    console.log('ตรวจพบการนอน:', data);
  });
};

// การตรวจจับแสงสำหรับการนอน
const startLightDetection = () => {
  startLightSensorTracking(500); // อัปเดตทุก 0.5 วินาที
  setOnLightLevelChangeCallback((data) => {
    if (data.lightLevel <= 5) {
      console.log('ความสว่างเหมาะสำหรับการนอน');
    }
  });
};

// การใช้เซนเซอร์ในเกม
const handleSensorMovement = (data) => {
  const { x, y } = data;
  // ย้ายตัวละครในเกมตามการเอียงของมือถือ
  setPlayerPosition(prev => ({
    x: prev.x + x * sensitivity,
    y: prev.y + y * sensitivity
  }));
};

🌐 3. API มีอะไรบ้าง
========================================

🔐 AUTHENTICATION APIs (3 endpoints):
├── POST /api/auth/register - สมัครสมาชิก
├── GET /api/auth/profile - ดูโปรไฟล์
└── PUT /api/auth/profile - แก้ไขโปรไฟล์

👥 USERS APIs (2 endpoints):
├── GET /api/users - ดูผู้ใช้ทั้งหมด
└── GET /api/users/:id - ดูผู้ใช้ตาม ID

📝 TASKS APIs - CRUD (4 endpoints):
├── GET /api/tasks - ดูงานทั้งหมด
├── POST /api/tasks - สร้างงานใหม่
├── PUT /api/tasks/:id - แก้ไขงาน
└── DELETE /api/tasks/:id - ลบงาน

🎮 GAMES APIs (3 endpoints):
├── GET /api/games - ดูเกมทั้งหมด
├── GET /api/games/scores - ดูคะแนนของผู้ใช้
└── POST /api/games/:gameId/score - บันทึกคะแนนเกม

😴 SLEEP APIs - CRUD (4 endpoints):
├── GET /api/sleep - ดูข้อมูลการนอน

🌍 ROOT API:
└── GET / - ข้อมูลภาพรวม API
