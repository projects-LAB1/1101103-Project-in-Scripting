# Assets Folder

## 📁 โฟลเดอร์นี้สำหรับไฟล์ทรัพยากร

### 🔊 Sounds
- วางไฟล์เสียงปลุกในโฟลเดอร์ `sounds/`
- รองรับไฟล์ .mp3, .wav, .m4a

### 🖼️ Images  
- วางไฟล์รูปภาพในโฟลเดอร์ `images/`
- รองรับไฟล์ .png, .jpg, .jpeg

### 📝 หมายเหตุ
ไฟล์ทรัพยากรถูกแยกออกเพื่อลดขนาดแพ็คเกจ
คุณสามารถดาวน์โหลดไฟล์ทรัพยากรแยกต่างหากได้
