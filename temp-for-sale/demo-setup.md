# การสร้าง Demo Page สำหรับการขาย

## วิธีที่ 1: GitHub Pages (ฟรี)

### ขั้นตอน:
1. สร้าง GitHub repository ใหม่ชื่อ `smart-alarm-demo`
2. อัปโหลดไฟล์ `live-preview/index.html` 
3. เปิดใช้ GitHub Pages ใน Settings
4. ได้ URL: `https://yourusername.github.io/smart-alarm-demo`

### ไฟล์ที่ต้องอัปโหลด:
- `index.html` (จาก live-preview/)
- `README.md` (คำอธิบายโปรเจค)

## วิธีที่ 2: Netlify (ฟรี)

### ขั้นตอน:
1. ไปที่ netlify.com
2. Drag & Drop โฟลเดอร์ `live-preview`
3. ได้ URL: `https://random-name.netlify.app`

## วิธีที่ 3: Notion Page

### ขั้นตอน:
1. สร้าง Notion page ใหม่
2. เพิ่มรูปภาพและคำอธิบายแอป
3. Share page เป็น public
4. ได้ URL: `https://notion.site/your-page-id`

## แนะนำ: ใช้ GitHub Pages

เพราะ:
- ฟรี
- เชื่อถือได้
- URL สวย
- ใช้งานง่าย
