# Screenshots สำหรับการขาย

## ภาพหน้าจอที่ต้องการ

1. **หน้าหลัก (Main Screen)**
   - รายการปลุกทั้งหมด
   - ปุ่มเพิ่มปลุกใหม่
   - สถานะปลุกต่างๆ

2. **หน้าตั้งปลุก (Add Alarm)**
   - ตัวเลือกเวลา
   - การตั้งค่าซ้ำ
   - เลือกเสียง

3. **หน้าเกม (Mini Games)**
   - Math Game
   - Memory Game  
   - Photo Game

4. **หน้าเสียง (Sound Picker)**
   - รายการเสียงปลุก
   - ตัวเล่นเสียง
   - การอัปโหลดเสียงใหม่

5. **หน้าสถิติ (Sleep Analytics)**
   - กราฟการนอน
   - สถิติต่างๆ
   - ข้อมูลสภาพอากาศ

## วิธีการ

1. รันแอป: `npm start`
2. จับภาพหน้าจอแต่ละหน้า
3. ขนาดแนะนำ: 1080x1920 (มือถือ) หรือ 768x1024 (แท็บเล็ต)
4. บันทึกเป็น PNG หรือ JPG
5. ใส่ไฟล์ทั้งหมดในโฟลเดอร์นี้
6. สร้าง ZIP: `screenshots.zip`
