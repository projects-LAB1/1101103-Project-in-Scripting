👤 สมาชิก A - Project Leader & Frontend

🎤 สคริปต์สมาชิก A:

นาทีที่ 1-2: เปิดการนำเสนอ
---------------------------
"สวัสดีครับ วันนี้กลุ่มเราจะนำเสนอโครงงาน Sleep App ครับ

ที่มาและความสำคัญ:
ปัจจุบันคนยุคใหม่มีปัญหาการนอนหลับ การใช้เทคโนโลยีช่วยติดตามการนอนจึงเป็นสิ่งสำคัญ เราจึงพัฒนาแอปที่ครบครันสำหรับการดูแลสุขภาพการนอน

วัตถุประสงค์:
1. พัฒนาแอปติดตามการนอน
2. สร้างระบบจัดการงาน  
3. เพิ่มเกมฝึกสมอง
4. ใช้ Sensor ในการตรวจจับ

ประโยชน์ที่คาดว่าจะได้รับ:
- ผู้ใช้ติดตามการนอนได้ดีขึ้น
- นอนหลับมีคุณภาพ
- จัดการงานได้ดี
- ฝึกความจำผ่านเกม"

นาทีที่ 7-8: อธิบาย Data Operations
----------------------------------
"ส่วนต่อไปผมจะอธิบาย Data Operations ของแอปครับ

Data Fetching (3+ จุด):
1. Weather API - ดึงข้อมูลสภาพอากาศ
2. Backend API - ดึงข้อมูลผู้ใช้, งาน, การนอน
3. Local Storage - เก็บการตั้งค่าแอป

Data Update (3+ จุด):
1. Profile Update - แก้ไขข้อมูลโปรไฟล์
2. Task Update - อัพเดทสถานะงาน
3. Sleep Data Update - แก้ไขข้อมูลการนอน

Data Create (3+ จุด):
1. User Registration - สร้างบัญชีผู้ใช้
2. Task Creation - สร้างงานใหม่
3. Sleep Record - บันทึกการนอน

Data Delete (3+ จุด):
1. Task Delete - ลบงาน
2. Sleep Data Delete - ลบข้อมูลการนอน
3. User Data Delete - ลบข้อมูลผู้ใช้"

นาทีที่ 14-15: สรุปโครงงาน
---------------------------
"สรุปโครงงาน Sleep App ของเรา:

ความคิดสร้างสรรค์:
- UI/UX Design สวยงาม
- การใช้ Animation
- Integration หลายระบบ

ผลกระทบต่อชุมชน:
- ช่วยแก้ปัญหาการนอนหลับ
- เพิ่มประสิทธิภาพการทำงาน
- ส่งเสริมสุขภาพจิต

โครงงานของเราผ่านเกณฑ์การให้คะแนนครบทุกข้อ พร้อมใช้งานจริง ขอบคุณครับ"

🕐 เวลารับผิดชอบ: 6 นาที (นาทีที่ 3-4, 9-13)

📋 หน้าที่หลัก:

🎤 สคริปต์สมาชิก B:

นาทีที่ 3-4: ขอบเขตโครงงาน
----------------------------
"ขอบเขตของโครงงานครับ:

1. React Native Mobile App
   - Cross-platform iOS/Android
   - Modern UI/UX Design
   - Responsive Layout

2. Express.js Backend API  
   - RESTful API Design
   - CRUD Operations ครบ
   - Authentication System

3. Firebase Integration
   - Firestore Database
   - Firebase Authentication
   - Real-time Sync

4. Sensor Integration
   - Light Sensor - ตรวจจับแสง
   - Location Sensor - ตรวจจับตำแหน่ง"

นาทีที่ 9-13: Demo Backend API
------------------------------
"ตอนนี้ผมจะ Demo Backend API ที่เราพัฒนาขึ้นครับ

[ทำตาม COMPLETE-EXPLANATION-GUIDE.txt]

Backend API ของเราใช้ Express.js เป็น Framework หลัก เชื่อมต่อกับ Firebase

เรามี API Endpoints ทั้งหมด 14 ตัว แบ่งเป็น 5 กลุ่ม:
1. Authentication (3 endpoints)
2. Users (2 endpoints)  
3. Tasks (4 endpoints)
4. Games (3 endpoints)
5. Sleep (3 endpoints)

[Demo การทำงาน API ตามสคริปต์]

จากที่แสดงให้เห็น Backend API ของเราครบทุกฟีเจอร์ มี CRUD Operations ครบ และทดสอบผ่านทั้งหมดครับ"

👤 สมาชิก C - Frontend Developer & UI/UX
========================================

🕐 เวลารับผิดชอบ: 4 นาที (นาทีที่ 5-6, 7-8)

📋 หน้าที่หลัก:
1. แสดง 5 หน้าจอ (นาทีที่ 5-6)
2. แสดง 5 Components (นาทีที่ 7-8)

🎤 สคริปต์สมาชิก C:

นาทีที่ 5-6: แสดง 5 หน้าจอ
---------------------------
"ผมจะแสดง 5 หน้าจอหลักของแอปครับ:

1. Login/Register Screen
   - ระบบเข้าสู่ระบบ
   - สมัครสมาชิก
   - Reset Password

2. Home Dashboard Screen  
   - แสดงสรุปข้อมูลการนอน
   - สถิติการนอนรายวัน
   - Quick Actions

3. Sleep Tracking Screen
   - บันทึกเวลานอน-ตื่น
   - ประเมินคุณภาพการนอน
   - กราฟแสดงผล

4. Task Management Screen
   - รายการงานที่ต้องทำ
   - เพิ่ม/แก้ไข/ลบงาน
   - จัดหมวดหมู่งาน

5. Games Screen
   - เกมฝึกสมอง
   - Memory Game, Puzzle Game
   - บันทึกคะแนน"

นาทีที่ 7-8: แสดง 5 Components
------------------------------
"ส่วน Components ที่เราสร้างขึ้น 5 ตัวหลัก:

1. CustomButton Component
   - ปุ่มที่ใช้ทั่วทั้งแอป
   - รองรับหลายสไตล์
   - Animation Effects

2. SleepCard Component
   - แสดงข้อมูลการนอนแต่ละวัน
   - กราฟคุณภาพการนอน
   - สีสันตามคุณภาพ

3. TaskItem Component  
   - รายการงานแต่ละอัน
   - Checkbox สำหรับทำเครื่องหมาย
   - Priority Indicator

4. GameCard Component
   - การ์ดแสดงเกมแต่ละอัน
   - คะแนนสูงสุด
   - ระดับความยาก

5. HeaderComponent
   - Header ที่ใช้ทุกหน้า
   - Navigation Menu
   - User Profile Icon"
