🔧 BACKEND FILES - หน้าที่ของแต่ละไฟล์
========================================

📄 server.js
-------------
หน้าที่: Main API Server
- Express.js server หลัก
- กำหนด API routes ทั้งหมด
- Authentication endpoints (/api/auth/*)
- Users endpoints (/api/users)
- Tasks endpoints (/api/tasks)
- Games endpoints (/api/games)
- Sleep endpoints (/api/sleep)
- Error handling middleware
- CORS configuration
- JSON parsing middleware

📄 firebase-config.js
----------------------
หน้าที่: Firebase Configuration
- Firebase Admin SDK setup
- Firebase Client SDK setup
- Firestore database connection
- Mock database สำหรับการทดสอบ
- Authentication configuration
- Database initialization

📄 firebase-config-example.js
------------------------------
หน้าที่: Firebase Config Template
- ตัวอย่างการตั้งค่า Firebase
- คำแนะนำการใช้งาน
- Template สำหรับ Service Account Key
- คำแนะนำการดาวน์โหลด credentials

📄 middleware/auth.js
---------------------
หน้าที่: Authentication Middleware
- ตรวจสอบ Firebase ID Token
- Verify token กับ Firebase Admin
- Mock authentication สำหรับการทดสอบ
- User data extraction จาก token
- Optional authentication middleware

📄 package.json
---------------
หน้าที่: Dependencies & Scripts
- Express.js framework
- Firebase Admin & Client SDKs
- CORS middleware
- UUID generator
- JSON Web Token
- Nodemon สำหรับ development
- NPM scripts (start, dev)

📄 test-api.js
--------------
หน้าที่: API Testing Script
- ทดสอบ API endpoints ทั้งหมด
- Mock data generation

- Error testing
- Performance testing
- Automated testing workflow
